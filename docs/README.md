# Documentation

This directory contains the offline technical/user manual and the image assets used by the repository documentation.

## Technical manual

- [MEA Visual Stimuli v2.0 — User Manual and Technical Reference](MEA_Visual_Stimuli_Manual_v2_0.pdf)

The v2.0 manual documents the validated experimental architecture used as the basis of the v2.1.x branch. It retains the historical **MEA Visual Stimuli** title; the current project name is **Visual Stimulator**, whose intended scope includes MEA/electrophysiology as well as other ex vivo, in vivo and general visual-stimulation experiments.
